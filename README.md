## 🏆 Featured Projects

> These projects live in private repositories for now. I am happy to walk through them or show the code in a conversation.

### 1. 🤖 AI Receptionist for Hair Salons
**Python · Flask · LLM Tool Use · Render**
A web chat where an AI assistant answers business questions (prices, opening hours, FAQs) and **books, looks up and cancels real appointments**.

- **Scheduling logic:** free slots, overlap handling based on staff capacity, and cancellation deadlines.
- **Business dashboard:** weekly view that refreshes automatically, plus manual booking for walk-ins and phone calls.
- **Multi-tenant:** every business has its own data and calendar; a new demo is created from a terminal wizard.
- **Engineering:** tests for the scheduler and dashboard that need no API key, plus rate limits per IP and per session.

### 2. 💇 Stylist-Aware Booking Assistant
**Python · Flask · LLM · Data Import**
A variant where **each service can only be booked with the stylists who actually perform it**. It handles a catalogue of ~95 services with duration and price, and includes a spreadsheet-to-JSON workflow (CSV → JSON) to complete the data.

### 3. 🌍 BWT — B2B Export Marketplace
**TypeScript · React 19 · TanStack Start · Supabase · Cloudflare Workers**
A platform connecting **industrial SMEs with verified commercial agents** for export operations in Europe. I am the technical co-founder (data, AI and development).

- **Automatic matching** between company needs and agents, with a 0–100 score and breakdown.
- **Three dashboards** (company, agent and admin), in-app messaging and an explicit deal lifecycle.
- **Agent verification** with documents and real-time EU VAT validation (VIES).
- **Interface in 5 languages** (EN / ES / FR / DE / IT), real-time notifications, deployed on Cloudflare Workers.
